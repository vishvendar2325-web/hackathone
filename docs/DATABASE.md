# FOCUSFLOW — Database Documentation & Schema Design

## 1. Overview
FOCUSFLOW utilizes PostgreSQL managed through Prisma ORM. The data model is structured around student focus habits, short-form video transition telemetry, peer study pods, and strict privacy safeguards.

## 2. Core Entities & Relationships

| Model | Purpose | Key Constraints & Indices |
|---|---|---|
| `User` | Core account credentials and identity | `@unique(email)`, `@index([role])` |
| `Profile` | Student academic level, targets, timezone | `@unique(userId)`, 1:1 with User |
| `Device` | Registered Chrome extension or web clients | `@index([userId])`, Cascade delete |
| `UsageSession` | Active domain duration (clean hostnames only) | `@index([userId, startedAt])`, `@index([domain])` |
| `DailySummary` | Aggregated daily focus & distraction totals | `@@unique([userId, date])` |
| `ReelDailyStat` | Estimated short-form video transitions | `@@unique([userId, date, platform])` |
| `FocusSession` | Recorded Pomodoro and Deep Work blocks | `@index([userId, startedAt])`, `@index([status])` |
| `FocusGoal` | Student academic milestones | `@index([userId])` |
| `BlockedWebsite` | Custom and category-based block rules | `@@unique([userId, domain])` |
| `AIRecommendation`| Structured suggestions generated by AI Coach | `@index([userId, createdAt])` |
| `XPTransaction` | Gamification points for focus milestones | `@index([userId, createdAt])` |
| `Achievement` | Badges unlocked by students | `@@unique([userId, badgeKey])` |
| `Streak` | Consecutive active study days counter | `@unique(userId)` |
| `StudyGroup` | Peer study accountability pods | `@unique(inviteCode)` |
| `GroupMember` | Membership and role within a study group | `@@unique([groupId, userId])` |
| `Notification` | System nudges, group invites, streaks | `@index([userId, isRead])` |
| `PrivacyConsent` | Transparent user tracking consent records | `@unique(userId)` |

## 3. Privacy-By-Design Principles
1. **Zero Full-Path Storage**: `UsageSession` and `BlockedWebsite` record domain names (e.g., `instagram.com`), never full URLs containing tokens, usernames, or search queries.
2. **Aggregated Estimates**: Reel counts are stored as daily integers, not timestamped individual video identifiers.
3. **Opt-In Cascading**: If `PrivacyConsent.hasConsentedTracking` is false, extension sync payloads are rejected.
